# AMOS

## Austin Mini Onboard System

### Introduction

This project is still at the prototype stage and does not represent the
intended final result. As a result, AMOS may contain bugs and can change
significantly from one version to another.

### Current status

- [x] Installable application
- [x] Clock display
- [x] Raspberry Pi statistics display
- [x] Logbook for recording fuel fill-ups
- [x] Update system
- [x] Startup animations
- [x] Wing fan activation
- [ ] Engine sensor installation
- [ ] Mobile application for communicating with AMOS (Android/iOS)
- [ ] Connection to the vehicle's sound system
- [ ] Sensor data logging
- [ ] GPS
- [ ] Automatic power-on when the engine starts
- [ ] Interior lighting power control
- [ ] More to come...

### Requirements

- Raspberry Pi (tested with a Raspberry Pi 4B 2 GB)
- Voltage step-down converter
- Switch
- Relay
- 800x480 capacitive touchscreen
- 3D-printed mounting brackets
- Raspberry Pi OS Lite
- SD card (ideally an official Raspberry Pi SD card)

### Project background

The idea for AMOS came from my Austin Mini Thirty. As it approached
200,000 km, its engine experienced repeated head-gasket failures. To preserve
it for as long as possible and anticipate potential breakdowns, I decided to
install an onboard computer.

The goal is to create a discreet system, installed in place of the front
ashtray, that provides useful information to the driver while monitoring and
logging data from sensors installed on the engine. I also wanted to avoid
filling the dashboard with additional instruments. The screen makes it
possible to display sensor readings while preserving the original appearance
of my Mini and adding a small touch of modernity.
